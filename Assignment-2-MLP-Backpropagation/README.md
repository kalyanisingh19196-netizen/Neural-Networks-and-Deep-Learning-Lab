Assignment 2: Multilayer Perceptron with Backpropagation

Objective

Implement a single-layer perceptron and a Multilayer Perceptron (MLP) using NumPy. Understand forward propagation, backpropagation, gradient checking, and weight initialization.

Tasks

1. Single-Layer Perceptron

* Implement a perceptron for binary classification.
* Demonstrate its limitation using the XOR dataset.
* Explain why a single-layer perceptron cannot solve XOR.

2. Multilayer Perceptron (MLP)

* Build an MLP using NumPy.
* Implement forward propagation.
* Implement backpropagation.
* Use a hidden layer to solve the XOR problem.
* Evaluate the model’s predictions.

3. Numerical Gradient Checking

* Implement numerical gradient checking.
* Compare analytical and numerical gradients.
* Verify the correctness of backpropagation.

4. Weight Initialization

Compare the following initialization methods:

* Zero Initialization
* Random Initialization
* Xavier Initialization
* He Initialization

Compare their effects on training performance and convergence.

5. Fashion-MNIST Classification

* Load the Fashion-MNIST dataset.
* Train an MLP using NumPy.
* Use suitable hidden-layer and output-layer activation functions.
* Evaluate model accuracy and loss.
* Visualize training results and the confusion matrix.

Technologies Used

* Python
* NumPy
* Matplotlib
* Pandas
* Scikit-learn
* TensorFlow/Keras (for dataset loading)

Expected Outcomes

* Understand perceptron limitations.
* Implement an MLP from scratch.
* Understand forward and backward propagation.
* Verify gradients numerically.
* Compare weight initialization techniques.
* Perform Fashion-MNIST classification.
